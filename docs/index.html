Genativity open data

The dataset behind Genativity, an independent benchmark and price tracker for AI video generation. Every model runs the same 40 prompts, every clip is scored, and prices are read twice a day across 17 platforms and APIs.

Download

  • leaderboard.csv (16 rows): One row per model: overall score, 95% confidence interval, sub-scores and the score in each test category.
  • scores.csv (698 rows): One row per scored clip: model, prompt, category, round and every judge score, with a link to the clip.
  • prices.csv (12,933 rows): Current published prices on every platform and API we track, normalised to USD per clip and per second.

Column definitions are in the repository README. Methodology: genativity.com/methodology.
